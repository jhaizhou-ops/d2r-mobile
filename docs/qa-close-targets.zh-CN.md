# 关闭 X 热区

原有九圈吸附最多搜索 90 个布局单位（按界面高度缩放）。现增加七圈，到 160 单位，仅限 `TouchClose`、`close` 和 `CloseButton`。直接命中、滑块和附近普通控件仍优先；普通控件不扩大范围。沿用原控件命中函数、可见性、面板裁剪和层级下限。物品区域分类仍先于吸附。

生产 `ui_snap` 回归使用两档分辨率的自造控件：16 项断言，修改前失败六项，修改后零失败，UBSan 也通过。覆盖横纵偏点、最大范围、普通按钮和隐藏关闭按钮。不包含游戏内容。

原生验证待完成（没有可执行文件和 RomFS）：在 iPad 检查背包、仓库、方块、商人、技能、任务、佣兵、设置和编年史。点击各 X 周边、相邻页签、格子、底板和模态框。确认扩展热区不关闭被遮住的面板、不抢物品或页签手势，设置仍保留应用/放弃确认。检查手柄/鼠标模式切换。修改后截图和真机结果补齐前保留草稿。
