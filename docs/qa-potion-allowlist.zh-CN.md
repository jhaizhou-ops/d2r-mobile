# 药水自动拾取边界（#9）

现有发送器已经限制原生回复/法力类型（含紫药）、腰带空位及掉落可见性。新增独立的物品代码白名单：仅 hp1–hp5、mp1–mp5、rvs 和 rvl。未知代码及耐力、解毒、解冻、卷轴、书和投掷药在资格检查及发包前排除。排序仍为大紫、小紫、红蓝档次。普通难度、关闭显示过滤也使用同一白名单。原生主动拾取和按难度显示过滤不改。

这是对所需边界的防御加固，不证明玩家反馈的物品来自这条发送器。现有证据无法区分普通难度下无意点中物名与其他原生交互。不能仅凭这些测试关闭 #9。

测试调用生产代码分类器：70 项断言，普通及 UBSan 通过，覆盖零/空格结尾代码、全部红蓝档次、两种紫药及排除代码。不覆盖游戏收包或类型表。

原生后续验证（当前没有可执行文件和 RomFS）：普通难度下，自动拾取、掉落过滤分别开/关，在红蓝紫药旁放置排除的消耗品。分别站立、摇杆经过、点击空地、施法、点击各物名；覆盖腰带满/空及背包/方块空间。按物品 ID 配对拾取请求/来源和落位日志；日志“玩家点的”仅表示未在宿主自动请求表中，不能证明物理触摸。确认物品数量及主动拾取正常，其他难度也测。不声称已原生复现或完整修复玩家反馈现象。
