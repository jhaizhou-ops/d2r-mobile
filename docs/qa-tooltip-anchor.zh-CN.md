# 装备预览位置（#48）

单独背包的旧策略把原生物品目标的横纵坐标都替换成对侧顶部。修改后保留侧边空板（维护方担心长说明遮住格子），选择靠近物品的一侧，并保留原生目标的 y 和高度。文字测量、上下选择及边界约束仍由游戏处理。仓库、商店、方块与佣兵路径排除。`DM_TEST_TIPDOCK=0` 用于原生锚点对照。

实际 OBS_TOOLTIP 回调配合自造控件检查物品四角、非目标寄存器不变及原生对照；普通与 UBSan 测试通过。它验证的是传给游戏的参数，不是最终渲染几何。

仍需原生验收：在 iPad 和宽屏 iPhone 检查短护身符、长符文之语、已装备物品、比较文本及背包四角。确认说明不出屏且不遮住物品格、腰带和存放按钮；检查仓库、商店、方块和佣兵位置。接受草稿前须附修改后真机截图。当前没有游戏可执行文件和 RomFS，不声称完成整包构建或 iPad 渲染验证。
