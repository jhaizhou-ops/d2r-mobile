# Mac 桌面 PC 界面与西班牙语支持——集成草案

此提案把本地验证过的桌面实现放在一个审查分支中。它是较大的集成草案，不请求未经审查直接合并。目标游戏版本为 Switch 3.3.94012；在现有按版本绑定的钩子上扩展。新增接口偏移和最终 PRODUCT 代号需要维护者确认。

## 范围

- 原始 PC HUD、面板、横向腰带和技能选择器，不显示移动端控件或手柄选择圆环。
- 鼠标点击移动、NPC 菜单、PC 物品栏/装备、手持物品绘制、拖放、仓库分页、商店/模态输入、原生按键分配和快速施法。
- Retina、黑边、窗口缩放及 UI/世界边界使用一致的坐标约定；事件携带各自坐标，手持物品只丢弃一次。
- Mac 窗口、最大化、全屏、渲染分辨率、游戏光标、精确滚动累积和惯性过滤。
- 西班牙语端口文本和注释、收藏名称、保留语法的物品备注、原生区域名称、居中的难度文字和编年史筛选/搜索布局。
- FFmpeg VP8 过场解码、音频焦点处理、独立 Mac 打包、本地生成图标/光标和依赖库打包。
- 宿主、原始指令和布局回归测试。不提交游戏文件、美术、着色器、存档、密钥、日志或编译后的 App。

商业文本、语音、布局和美术均从用户自己的游戏文件读取。光标 PNG 在构建/测试时生成到仓库外的工作区缓存。链接式包通过 paths.txt 引用缓存，不复制光标图片。独立包只供本地私人使用，不得分发其中的派生文件。

## 前置依赖与启用方式

先完成仓库正常准备流程并使用准确的支持版本。Mac 新增部分需要 pkg-config、FFmpeg 开发库（libavformat/libavcodec/libavutil/libswscale）和 dylibbundler，以及已有 Xcode、Metal 和 Python 依赖。构建前用自己的包管理器安装；setup.sh 尚未安装或完整检查新增依赖。FFmpeg 及其链接库保留各自许可证；分发仅宿主的包前也要核查所选 FFmpeg 构建的许可证配置。

PC overlay 需要显式启用；普通 Mac overlay 不会自动变为 PC 界面：

```bash
export DM_ROOT="$HOME/dm-work"
export DM_OVERLAY_PC=1
./setup.sh
make -C dm/host dmhost
DM_MAC_LINK=1 bash dm/tools/mac_app.sh "$DM_ROOT/out/mac-pc-review"
```

改写程序、overlay、PRODUCT 与着色器反射/工具链标识必须保持一致。按正常流程本地生成三个着色器链文件；本 PR 不提交它们的本机修改。不要重用过时的产品缓存。本地独立包使用 DM_MAC_LINK=0；可选 DM_MAC_ROMFS_COPY=1 和 DM_MAC_ICON_SOURCE 读取自己的资源。不要上传这个包。

游戏原生选项/控制界面管理游戏按键。选择并应用 Resurrected 预设可获得技能 1–6、药水 QWER；按需启用快速施法和活动技能按键。Mac 附加控制表只管理两个物理鼠标键。测试前备份现有存档/设置，测试运行使用单独的 DM_APP_SUPPORT，再单独验证真实配置；不公开存档或偏好文件。

## 复现与验证边界

对本分支执行 CONTRIBUTING.md 中的检查，明确列出未执行项。宿主测试从本地 RomFS 生成光标缓存；仓库测试声明生成头文件依赖。历史比较通过 DM_TEST_PREVIOUS_NOTES、DM_TEST_LEVEL_REFERENCE、DM_TEST_PAUSE_REFERENCE 或 DM_TEST_COLLECTION_OVERLAY 可选启用，不要求原工作站目录。

```bash
make -C dm/host/tests run
make -C dm/host/tests movie-real MOVIE_WEBM=/path/to/local.webm MOVIE_NV12=/path/to/first-frame.nv12
```

第二个目标明确编译 FFmpeg 路径。普通旧 movie 单测本身不覆盖它。至少31帧且有变化的纯 VP8 合成视频和独立解码的首帧 NV12 即可测试协议，不需共享商业视频。

原本地构建验证了 NPC 对话/交易、手持物品和拖放、仓库转移、站立/快速施法、清除敌人悬停、编年史页签/搜索、难度文字、窗口模式、原生改键及持久化、冷启动和暂停存档退出。这些结果只对应被测本地构建，不代表所有章节或重新基于 main 并调整导出后的分支。模拟滚轮/PCM 检查不证明物理触控板体验或每段声音/输出设备。原始截图和日志可能含私人角色名或路径，因此未附上。
