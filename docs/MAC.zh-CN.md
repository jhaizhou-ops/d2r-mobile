# 在 Mac 上玩（macOS App）

English: [MAC.md](MAC.md)

Apple 芯片的 Mac 可以把本项目构建成一个原生的 macOS App：`D2R Mobile.app`，双击启动，键盘、鼠标、手柄都能用。它跑的是同一份游戏、同一套我们加的功能（秘境、珍宝匣、编年史、自定义页等），界面用的是原版的手柄版界面。

**先说在前面：下面这五项还未经真人操作**——键盘按键、实体手柄、选资源文件夹的对话框、⌘Q 与菜单点击、真人手感。下面写「验过」的，都是无人值守跑出来的：按键用测试脚本注入，鼠标用测试入口注入，退出、全屏、改窗口大小用测试开关。你试过的话，请开 Issue 把结果告诉我们。

## 系统要求

Apple 芯片（Intel 芯片的 Mac 不支持；各设备的情况见首页「[支持哪些设备](../README.zh-CN.md#支持哪些设备)」）。按系统分两档：

| 你的系统 | 用哪种出法 | 产出 |
|---|---|---|
| macOS 26 及以上 | 缺省：`dm/tools/mac_app.sh` | `D2R Mobile.app` |
| macOS 15 – 25 | 老接口版：`DM_MAC_M3=1 dm/tools/mac_app.sh` | `D2R Mobile M3.app` |

缺省的构建把图形部分建在 macOS 26 才有的图形接口（Metal 4）上，更早的系统上打不开（系统会提示这个 App 不能与当前版本的 macOS 配合使用）。老接口版是同一份源码、同一个游戏，图形部分改用老系统也有的接口，最低 macOS 15.0；细节见 [OLDER_SYSTEMS.zh-CN.md](OLDER_SYSTEMS.zh-CN.md)。

## 构建

前提与 iOS 那条路相同：游戏文件放到位，`./setup.sh` 跑完（见首页「开始使用」）。然后：

```bash
source ~/dm-work/build/cache/dm/venv/bin/activate
dm/tools/mac_app.sh                  # macOS 26 及以上
DM_MAC_M3=1 dm/tools/mac_app.sh      # macOS 15 – 25
```

缺省出法约十几秒，产出 `~/dm-work/out/macapp/D2R Mobile.app`（约 3 MB）。老接口版第一次要把着色器库按 macOS 15 重编一份，多花约 3–4 分钟，产出 `D2R Mobile M3.app`；它有自己的存档与日志目录（名字里带 M3），可以和缺省的 App 并存。想放到别处：命令后面跟输出目录。

这个 App 里只有我们自己的程序。改写后的游戏程序、着色器库、界面覆盖层都是从你的游戏文件做出来的，它们留在你的工作区（`~/dm-work`）里，App 只记着它们的位置——所以**这个 App 只能在构建它的这台 Mac 上跑**，请不要拷给别人，也不要删掉或挪动工作区（老接口版重编的着色器库就在输出目录里）。签名用的是本机临时签名，不需要开发者账号，也不需要登记设备。

版本号与构建号可以指定：`DM_MAC_VERSION`（缺省 1.0）、`DM_MAC_BUILD`（缺省取当前的月日时分）。

## 第一次打开

双击 App。第一次启动会请你选**游戏资源文件夹**：选 `~/dm-work/data/switch/3.3.94012/Update`（或它里面的 `RomFS`）即可，里面要有 `data` 文件夹；直接选装着各个 `.data` 和 `build_manifest.psv` 的那个文件夹也可以。选错了会说明原因并让你重选；选对之后会记住，下次不再问。

接着会弹一次键位对照表，之后在菜单栏「帮助」里随时能看。

语言：首次启动跟系统语言（中文系统进中文，西语进西语，俄语进俄语，其余进英文）。想换：设置 →「自定义」页第一行的语言开关 → 全部接受 → 把 App 关掉重开。

## 键盘 ↔ 手柄

用键盘时，屏上的按键提示（底部提示条、技能格、页签两端）直接显示键盘上的键：J K U I Q E Z C = Tab 等；接上手柄按一下，自动换回手柄字母。完整对应如下：

| 要做的事 / 手柄键 | 键盘 |
|---|---|
| 确认（A） | 空格 或 J |
| 返回（B） | Esc 或 K（局内没有面板开着时，Esc = 打开物品栏那组页面） |
| 回车 | 确认；页面底部有「＋」提示时是 ＋（如起名之后的「接受」）；主菜单上回车 = 进入游戏 |
| ＋（菜单 / 新角色） | = 键 |
| −（地图） | Tab |
| 左摇杆（移动） | W A S D |
| 十字键 | 方向键 |
| X / Y | U / I |
| L / R | Q / E |
| ZL / ZR | Z / C |
| 按左摇杆 / 按右摇杆 | F / G |

**建一个角色，从头到尾这样按**：主菜单按 `=`（或鼠标点「新角色」）→ 用方向键选职业再按回车（或直接点那个职业的人物）→ 模式页按回车或空格 → 起名页按回车弹出输入框，直接打字，回车 → 再按一次回车创建。

接上手柄直接可用，与键盘并存。菜单栏有「显示 → 全屏（⌃⌘F）」和「退出（⌘Q）」。窗口可以随意拉大小。进游戏后画面按窗口 / 屏幕的比例铺满（16:10 的 MacBook 上窗口态和全屏态都铺满，界面贴底，开着大面板时界面居中）；主菜单、选角等前端页仍是 16:9、上下留边。

## 鼠标

现在能做的：

- **点空地走过去**：左键点一下空地，角色走到那一点，会自己绕开障碍；点在墙里、水里就走到能到的最近处。
- **按住一直走**：左键按住不放，角色一直朝鼠标所在的地方走，鼠标挪到哪跟到哪。W A S D / 手柄摇杆优先：走着的时候按方向键，立刻听键盘的。
- **点怪 = 攻击**：左键点一只怪，用主攻击键（J）上绑的技能打它——近战会自己走过去打，法术 / 远程直接对它放。按住不放一直打、追着打；光标下不是怪时照旧朝光标走。右键仍是返回。
- **点世界里的目标**（NPC、箱子、传送点、地上的物品）：走过去交互。面板开着时点面板外只关面板。
- **物品认鼠标了**：单击选中看说明；双击 = 使用 / 穿上 / 卸下（腰带里的药 = 喝，魔盒 = 打开，商人的货 = 买）；按住拖 = 拿起、松手放下（换格、穿到身上、进储藏箱 / 魔盒、拖进背包 = 买、拖到货架 = 卖），物品图就在光标上；在空格上按住 = 整理这一页。
- **点底部那一排**：技能图标 = 放那个技能（等于按它下面标的键），药水格 = 喝那格药，中间的钮 = 打开物品栏那组页面，跑 / 走钮 = 切换。
- **点界面**：面板里的按钮、勾选框、页签（含技能树页里的分页）、暂停菜单、设置页、秘境选层页的「开始」与右上角的关闭 X。
- **点底部的按键提示**：点哪一条，等于按那个键。
- **建角时点人物**：点哪个职业的人物就选哪个。
- **右上角小地图**：进局自动打开，按 Tab 开 / 关；点它顶上的地名那一条 = 切到全屏地图，再点一下回来。
- 右键 = 返回（B），滚轮 = 滚列表。

还不能的：

- 点地走只在营地验过空地与小站；野外复杂地形、点 NPC 未经验证。
- 设置页、储藏箱开着时换输入设备（键盘 ↔ 手柄），按键提示要等面板关掉才换。
- 物品的**长按**（看更多说明 / 取一件）在鼠标上是按住不动；这些手势和触屏上的是同一套。
- 「按住…」类的按键提示点一下不够长，用键盘按住；一条提示带两个键帽的不认。
- 血球、魔球、经验条点了没有反应。

## 存档、日志与 iCloud

- 存档：`~/Library/Application Support/D2R Mobile/save`
- 日志：`~/Library/Logs/D2R Mobile/host.log`（上一次运行的是 `host.prev.log`）。报问题时用菜单栏「帮助 → 分享日志…」：它把这两份日志和一份版本信息打成一个压缩包，让你选保存位置；不上传、不带存档，日志里的用户名会换成 `~`。
- 没有声音时看日志：启动时有一行「audio：输出设备「…」，系统缺省输出「…」」，两者不一致会标红；退出时有一行「声卡回调累计 N」，N 为 0 表示这次没有出声。
- 老接口版（`D2R Mobile M3.app`）用的是名字里带 M3 的另一对目录。

**iCloud 存档同步：从本仓库自己构建的 App 没有。**程序里接了与 iPhone / iPad 相同的同步，但它需要 App 带着 iCloud 的签名权限；自己构建的 App 用的是本机临时签名，没有这项权限，所以存档只留在这台 Mac 上，日志里会记一行「iCloud 不可用…只用本地存档」，游戏照常。要把手机上的进度带过来，用下面的手工导入。

### 从 iPhone / iPad 导入存档

导入是手工拷一次：拷完之后两边各玩各的，进度会分叉；以后想合到一起，只能再整份拷一次、以其中一边为准覆盖另一边。

**1. 在 iPhone / iPad 上找到存档**

- 先把手机 / 平板上的游戏完全退出（从多任务界面划掉）。
- 打开系统自带的「文件」App →「我的 iPhone」（或「我的 iPad」）→「D2R Mobile」→ 里面的 `save` 文件夹就是存档。

**2. 拷整个 `save` 文件夹，不要挑文件**

里面每个角色一个文件夹（文件夹名 = 角色名），另有共享仓库的几个文件和一个 `Settings` 文件夹（游戏设置，含界面语言——拷过来后 Mac 上的游戏设置会变成手机上那份）。我们加的功能（个人仓库的另外几页、百宝囊、秘境纪录、编年史仓库等）的数据也都在这个文件夹里。「自定义」页的开关不在里面，两台设备各管各的。

用隔空投送、数据线（访达里的「文件」页）或 iCloud 云盘把它传到 Mac 上都行。

**3. 放到 Mac 上**

1. 把 Mac 上的游戏完全退出（⌘Q）。
2. 在访达里按 ⇧⌘G，输入 `~/Library/Application Support/D2R Mobile` 回车。（这个文件夹在游戏第一次启动后才有。）
3. **先备份**：把里面现有的 `save` 文件夹改个名字（比如 `save 备份`），别删。
4. 把从手机拷来的 `save` 文件夹放进来。放对的样子是：`D2R Mobile/save/` 下面直接就是各个角色文件夹、`Settings`、几个 `.d2i` 文件——不要多套一层（不是 `save/save/…`）。
5. 旁边若有 `save.work`、`save.new` 不用管，游戏启动时会丢掉重建。
6. 打开游戏，主菜单上应当出现手机上的角色。

放错了或想恢复：退出游戏，把刚放进去的 `save` 拿走，把第 3 步改了名的那份改回 `save`。

反方向（Mac → iPhone / iPad）文件是同一套，做法对称：Mac 上退出游戏，把 Mac 的 `save` 拷到手机「文件」里游戏文件夹下替换原来的（先把手机上原来的改名备份）。两边的 App 尽量都用最新的。

验过的：在 Mac 上把一份存档按上面第 4 步的摆法放进存档目录，启动后主菜单显示出那份存档里的角色，能进局（无人值守一局）。从真的 iPhone / iPad 经「文件」App 拷出来再放进 Mac 的整个过程、反方向、专家模式角色，未经真人操作。

## 退出与存盘

关窗口、⌘Q、菜单里点退出，在任何状态下都会先存盘再退：局内、暂停菜单开着、面板开着、读取画面、秘境面板开着各验过一局。最多等 3 秒；到点还没存成，会在日志里记一行「未存盘退出」。

被强制退出或崩溃之后再打开，不会再有系统那个「要重新打开窗口吗」的框挡住游戏窗口。

## 已知不足

- 开头说的五项未经真人操作：键盘按键、实体手柄、选资源文件夹的对话框、⌘Q 与菜单点击、真人手感。键位是照键码表写的。
- 点地走只在营地验过。隔着墙点远处的怪，角色可能走到障碍前就停，绕一步再点。远程职业点怪、珍宝匣自动归位在鼠标拖放下，未经验证。PC 版的右键技能没有。
- 「分享日志」的菜单项与保存面板未经真人操作，验过的是打出来的压缩包。
- 「接上手柄提示换回手柄字母」是模拟验的，实体手柄没接过。
- 手柄上 ZR 空格的免费回城没有。
- 秘境左侧的任务栏没有。
- 自己构建的 App 没有 iCloud 存档同步，也不做更新检查（它不联网）。
- 老接口版在 macOS 15 上由一位内测玩家实际玩过（Mac mini M4，macOS 15.7，用的是出好的包）；在 macOS 15 的 Mac 上从本仓库自己构建，未经真人操作。
