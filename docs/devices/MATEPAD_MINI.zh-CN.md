# MatePad mini：鸿蒙实验性适配报告

English: [MATEPAD_MINI.md](MATEPAD_MINI.md)

本报告来自一台实机，测试日期为 2026-10-24。**它不代表发布壳已兼容此设备**：进入游戏使用的是本地重新构建的实验性个人包，完整兼容改动未包含在本说明文档 PR 中。

## 环境与范围

- 华为 MatePad mini，型号 MLR-AL00；Maleoon 910 GPU。
- HarmonyOS 7.0.0.109 SP6，设备实报 API 26，页大小 4 KiB。
- 源码基线：v2.0，`b811b90172f4eb40ec1bc89d903308e0c5ab88d0`，另有本地改动；壳基线为 0.19.6/code125。
- 自有 Switch 数据：1.0.34.0 / 3.3.94012；运行包针对 `ohos` 生成。
- 调试签名、验签和覆盖安装成功。

## 本地处理前观察到的启动阻塞

1. 匿名可写内存转为可执行时，`mprotect` 返回 `EINVAL`；也测试了独立、对齐的分配。仅凭此结果不能断言具体系统策略，也不能推及其他设备。
2. 越过可执行内存阻塞后，着色器校验拒绝非计算阶段的 subgroup 操作；设备报告的 subgroup 阶段支持仅有计算阶段（`0x20`）。

个人构建通过系统链接器加载本地生成、签名的 guest ELF 库，并在继续运行前检查映像大小、与导入运行包逐字节比较。这些库包含由游戏生成的数据，不是可以分发的纯壳资产。

离线检查发现 182 个含 subgroup 操作的非计算着色器。现有 quad 改写配合死代码、能力清理可处理其中 176 个；余下六个采用了独立的实验性改写。所得模块全部通过 SPIR-V 校验，**但这不等于完整画面等价证明**。本报告不附着色器二进制、生成表、游戏专用着色器标识或个人安装包；这些实验需要单独审查实现，才能宣称发布版支持。

## 个人构建的测试结果

已实际操作角色选择、进入营地、移动、攻击、菜单/地图及多个区域探索。日志确认存档事务提交并返回选角页。用户报告多次手动启动；拟进行的三次自动冷启动检查在一次锁屏拦截后停止，未完成。重载后的具体角色进度未独立核对。

两项性能发现可供后续独立改动参考：

- 带缓存、非一致性回读内存对每个小视图都使整个 32 MiB arena 分配失效。本地按 atom 对齐的范围实现保留了原有栅栏、屏障，并通过独立的实机回读检查。一次同进程营地对照中，缓存失效耗时中位数约为 7.9 ms 与 0.04 ms，采样平均帧率约为 23 与 28。自适应节拍、温控及频率存在变化，不能当作一般游玩性能结论。
- 新地形加载的慢帧包含环境立方体贴图的重复完整 BC6H 解码。本地有容量上限、逐字节比较压缩块的缓存，通过了与原解码器的 640 次主机图像比较；平板前两次符合条件的上传也与完整解码结果一致。随后测试了一次预留临时上传缓冲空间。用户反馈有所改善，但地形边缘仍有短促掉帧。这些本地实验不属于本 PR 的代码改动。

最终个人配置采用原生界面输出，3D 比例配置 0.50、GPU 驱动下限 0.46，节拍上限 30 FPS。静止场景可接近 30 FPS；部分跑图测试进入新地形时仍降到十几帧，较长日志也有贴图处理及首次管线创建停顿。**尚未验证持续 30 FPS、完整画面正确性及所有场景稳定性。**
