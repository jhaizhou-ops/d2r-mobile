# 浏览器 IPA 打包器

English: [WEB_IPA_PACKAGER.md](WEB_IPA_PACKAGER.md)

在 Windows 或 macOS 的桌面 Chromium 浏览器中，用自己的游戏文件生成 IPA。处理在本机完成，不上传游戏文件或密钥，也不需要安装 Xcode、Python、.NET 或编译器。生成的应用在 iOS 上原生运行，不是在浏览器里运行；维护者已确认生成的 IPA 可在真机上正常运行。

## 准备文件

将以下文件直接放在同一个文件夹中：

- 受支持的本体 NSP 和兼容的更新 NSP。
- `prod.keys`。
- 可选的兼容 DLC 和 `title.keys`。内嵌票据可以提供标题密钥；受权限保护的内容仍需要可用票据或匹配密钥。

请使用自己合法取得的游戏文件和密钥。本仓库不分发这些内容。打包器根据经过认证的元数据选择兼容内容，不依赖文件名。

## 生成与安装

1. 在受支持的桌面浏览器中，通过 HTTPS 打开打包器。页面会先检查浏览器能力并加载经过校验的公开运行时，再允许选择私有输入。
2. 选择输入文件夹并授予读写权限。原始 NSP 和密钥文件不会被覆盖。
3. 选择目标和可选设置，然后开始生成。开始前仍可更改设置。
4. 下载完成的 IPA。如果自动下载被拦截，点击页面上的下载链接。保存位置由浏览器决定。
5. 签名并安装 IPA。可选的浏览器本地签名需要自己的 P12/PFX、导出密码和匹配的描述文件，详见[签名准备](../web/docs/ipa-signing.md)。签名凭据不会发送到签名服务器。签名后的 IPA 包含描述文件，但不包含私有签名身份或密码。不使用本地签名时，请另用签名工具。
6. 使用“文件”将输入文件夹中生成的完整 `data` 文件夹复制到 **我的 iPhone / D2R Mobile**，或 iPad 上对应的应用目录。保留文件夹名称和内容。游戏资源与 IPA 分开存放。

已有的 `data` 文件夹只有在与当前输入完整比对通过后才会复用。不匹配时停止导出，不修改原文件夹。如果明确跳过原始资源导出，必须已有与本次游戏、更新和 DLC 匹配的资源；此模式下浏览器不会校验它们。

实验性的**老 GPU 选项**还会生成独立的 `Legacy Device Pack` 文件夹（重名时加 `-2`、`-3` 等后缀）和匹配的 IPA 覆盖层。将完整补充包与 `data` 并列复制，保留补充包自身的 `data` 子目录和 `manifest.json`。IPA 与补充包必须来自同一次生成。已报告的真机测试不涵盖此选项。

## 限制与恢复

- IPA 使用 ZIP32，归档上限为 512 MiB；最终下载 Blob 可能占用相应内存。大体积游戏资源单独流式导出，仍受磁盘空间、浏览器配额和组件限制约束。
- 每个会话只能生成一次。取消后请刷新页面再试。
- 不要复制未完成的资源。后续 IPA 步骤失败时，已经完整导出的资源仍可能有效。
- 公开运行时在处理私有输入前下载。没有远程转换服务或运行时 CDN 回退。JavaScript 内存清理不等于安全擦除。
