# dm/i18n：界面文字的多语表与字面量闸门

English: [README.md](README.md)

我们在原版之上加的界面文字都有中文、英文、西语、俄语几份，登记在这里的一张表里；一个扫描脚本保证没有文字绕过这张表。游戏原有的文字不归这里管，它们跟着游戏自己的字符串表走。

## 三个文件

| 文件 | 是什么 |
|---|---|
| `ui_text.tsv` | 多语表，我们加的界面文字的唯一来源。六列，制表符分隔：`键`、`中文`、`English`、`Español`、`Español MX`（空 = 同 Español）、`Русский`、`用在哪` |
| `scan_literals.py` | 字面量闸门：扫源码里含中文的字符串字面量，凡是会上屏又没走中英表的就报红 |
| `literal_whitelist.tsv` | 闸门的白名单：确实不上屏的中文字面量在这里登记。三列：`文件`、`匹配`、`理由` |

读这张表的是 `dm/ios/tools/dm_i18n.py`，它用表做两件事：

- **游戏里画的字**：构建覆盖层时把每一行追加进游戏的字符串表，简体与繁体中文两列放中文，esES / esMX 放西语，ruRU 放俄语，其余语言放英文。布局里写 `@键`，宿主里用 `dm_str` 按键取。换语言由游戏自己完成。
- **游戏外画的字**（系统弹框、资源下载页等）：生成 `dm/host/dm_i18n_tab.h` 编进程序，用 `dm_ui` 按键取。

取串的接口在 `dm/host/dm_i18n.h`。

## 怎么加一条界面文字

1. 在 `ui_text.tsv` 里加一行，每种语言都填（`Español MX` 与 `Español` 相同时可留空）。规则由 `dm_i18n.py` 把关，不合就报错：

   - 键以 `dm` 开头，后面只能是字母和数字，不能有下划线（布局里的 `@键` 遇到下划线会断开）；键不能重复，也不能与游戏原有的键重名。
   - 除 `Español MX` 外都不能空；除中文列外不能有中文字符（自定义页语言那一行是例外，见 `EN_HAS_ZH`）。
   - 占位符（`%d`、`%s` 等）与中文列必须个数相同、顺序相同、类型相同；换行数必须与英文列相同。
   - 要换行就写 `\n` 两个字符。
   - 一部分键（秘境面板、秘境提示等）有英文字数上限，超了会报出上限是多少；上限表是 `dm_i18n.py` 里的 `EN_LIMITS`。字数只是近似，新的英文进表后仍要出图看一眼有没有顶出框。
   - 「用在哪」一列没有脚本检查。现有各行在这里写这条文字出现在哪个界面、由哪个文件用、占位符各代表什么，照着写。

2. 重出生成头文件，并把它和表一起提交：

   ```
   python3 dm/ios/tools/dm_i18n.py --header > dm/host/dm_i18n_tab.h
   ```

3. 在代码里用键，不写字面量：布局脚本（`dm/ios/tools/touch_layout.py` 等）里写 `@键`；宿主里游戏内的字用 `dm_str(main_base, "键")`，游戏外的字用 `dm_ui("键")`。

4. 跑下面两条检查。

## 两条检查

```
python3 dm/ios/tools/dm_i18n.py --check
python3 dm/i18n/scan_literals.py
```

两条都只读源码，不需要游戏文件；`make -C dm/host/tests run` 里也会跑它们。

第一条核对表里每一行合不合上面的规则，以及入库的 `dm/host/dm_i18n_tab.h` 是不是由当前的表生成的。通过时打印 `dm_i18n OK <条数> 条`；头文件过期时会给出重出的命令。

第二条是字面量闸门。

## 字面量闸门怎么判

`scan_literals.py` 扫这些文件里含中文的字符串字面量：

- `dm/host/` 下的 `*.c`、`*.m`，`dm/ios/Sources/` 下的 `*.m`、`*.c`；
- 会把内容写进游戏的布局与素材生成脚本，名单写在脚本的 `PY_FILES` 里。新加这类脚本时要把它加进名单，否则闸门扫不到。

下面这些不算：注释、Python 文档串，以及最内层调用是日志或报错函数的字面量（`LOG`、`fprintf`、`NSLog`、`print` 等，名单是脚本里的 `SINK`）。

剩下的每一条都必须在 `literal_whitelist.tsv` 里有一行，否则报红。「匹配」一列有四种写法：

| 写法 | 含义 |
|---|---|
| 一段文字 | 字面量里含这段文字 |
| `=` 加整个字面量 | 字面量与它完全相同 |
| `@` 加函数名 | 字面量的最内层调用是这个函数 |
| `*` | 整个文件 |

「理由」写清这段中文为什么不上屏（例如只进日志）。白名单里不再匹配到任何字面量的行同样报红，要删掉。

结果：

- 通过：`I18N OK：中文字面量 N 条全在白名单（M 行），其余走中英表`，退出码 0。
- 不通过：以 `I18N 红` 开头，逐条列出文件、行号与字面量，退出码 1。
- `python3 dm/i18n/scan_literals.py --list` 列出全部命中的字面量与它们的最内层调用，写白名单时用。

报红时先想这段字是不是玩家看得到的：看得到就进中英表、代码里改用键；确实不上屏才加白名单。闸门只认含中文的字面量，直接写死的英文它拦不住，同样要进表。
